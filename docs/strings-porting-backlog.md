> Generated by `make strings-report` (which runs both the report and the backlog).

> `dispositionNote` set in `sangeet-core/src/main/resources/ui-strings.json`,
> it drops off this list.

Total PENDING entries: **434** across 149 components.

## Workflow

For each PENDING entry below:
1. Decide if it is an **easy port** (web has an equivalent UI element — just add `title` attr
   or merge with the parallel `.desktop` variant) or a **needs-UI** port (web is missing
   the element entirely; add a button/menu/dialog first).
2. Land the change, then set `dispositionNote` in `ui-strings.json` — either
   `"ported in <commit-sha>"` for completed ports or `"needs UI: <one-line>"` to keep
   the entry PENDING while capturing the rationale.
3. Re-run `make strings-report` to refresh both the parity report and this backlog.
